# AF Steel Furniture — Premium Steel Furniture & Accessories Website

A stunning, premium, fully client-side website designed for **AF Steel Furniture**, a bespoke manufacturer of high-end steel furniture and steel accessories based in Cape Town, South Africa. 

They design and manufacture every possible steel furniture piece and accessory with unmatched precision, durability, and aesthetics.

This website is built entirely with modern, raw **HTML5, CSS3, and Vanilla JavaScript** for unmatched loading speed, responsiveness, and control. It uses standard browser `localStorage` to handle all operations dynamically without requiring any backend server or database setup!

## 🚀 How to Run & Use

Because this is a pure client-side application, running it couldn't be simpler:

1. **Open the Website**: Simply double-click **[`index.html`](file:///c:/Users/ksham/OneDrive/Desktop/Steel-Forge-Website/index.html)** in your File Explorer to open it in any web browser of your choice.
2. **Accessing the Admin Dashboard**: Scroll to the footer of the homepage and click the **Admin** link, or directly double-click **[`admin.html`](file:///c:/Users/ksham/OneDrive/Desktop/Steel-Forge-Website/admin.html)**. 
   - *Note: All updates you make to products, categories, or reviews inside the Admin Dashboard will save instantly to your browser's local storage and reflect immediately across all pages!*

## 🎨 Technology & Design System

- **Styling (`style.css`)**: Implements a curated dark-mode and glassmorphic aesthetic using warm wood accents and brushed steel color palettes, modern fluid typography (Inter & Playfair Display), custom CSS grid layout, smooth micro-animations, and complete responsive design for mobile, tablet, and desktop viewports.
- **Interactions (`script.js`)**: Leverages clean, modular Vanilla JS to handle state management for `localStorage` data, smooth scrolling, dynamic filter rendering, slide-in viewport scroll animations, mobile nav menus, and lightbox interactions.
